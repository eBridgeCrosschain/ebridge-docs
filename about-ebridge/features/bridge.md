# Bridge

On the "**Bridge**" page, you can perform cross-chain transactions between the aelf chains chains and other chains.

* Supported aelf chains: aelf MainChain and aelf dAppChain.
* Popular supported tokens: ELF, USDT, USDC, ETH, BNB, DAI, and more popular tokens.
  * If you want to add a new token in eBridge, you can find the "**Add token**" entry in the pop-up modal for selecting tokens and follow the instructions. For detailed steps, see: \[FAQ - New Tokens]

For detailed cross-chain transfer instructions, see: \[FAQ - How do I initiate a cross-chain transfer on eBridge?]
