# Introduction

Welcome and you can find the necessary information here.

\
The eBridge cross-chain service is developed by the eBridge team within the aelf community. It supports cross-chain transactions between the aelf chains chains and other chains. And users can add custom tokens to the eBridge service on their own, after the addition is completed, the token will be available for cross-chain transactions.

The eBridge service focuses on enabling asset interoperability between different blockchain networks.

\
**Enhanced Interoperability**

* eBridge breaks down the barriers between the aelf chains chains and other chains, enabling true cross-chain interoperability.
* Users can freely transfer assets between different chains, enjoying more convenient cross-chain services.

**Increased Flexibility**

* Users can autonomously add tokens and manage Token Pools.
* This provides more autonomy and flexibility for token issuers and traders.

**Security Assurance**

* eBridge adopts advanced security technologies to ensure the security and reliability of cross-chain transactions.
* Provides transaction confirmation and multi-signature security mechanisms to protect user asset safety.

**Low Cost**

* eBridge charges no additional fees – the tokens you pay are used exclusively to cover gas fees on chains.
